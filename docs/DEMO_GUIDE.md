# Mentor — University Demo Guide

A concise presentation flow.

## 1. Problem — 30 seconds

Explain that teaching information is often split across calendars, notes, folders, and spreadsheets. Mentor combines the operational workflow into one local desktop application.

Key line:

> Mentor answers: what do I teach today, who am I teaching, what needs attention, and what happened previously?

## 2. Home — 45 seconds

Show the live statistics, today's lessons, quick actions, recent activity/goals/due work, and floating dock.

Mention that values are database-backed rather than decorative placeholders.

## 3. Lesson lifecycle — 90 seconds

1. Create a lesson.
2. Set student, subject, date/time, recurrence/template.
3. Open Lesson Details.
4. Mark it complete.
5. Record attendance.
6. Add notes and optional homework in the wrap-up flow.

## 4. Student intelligence — 60 seconds

Open a Student Profile and show lesson history, upcoming work, attendance, linked notes/materials/tasks, and assignments.

## 5. Notes, Materials, Search — 45 seconds

Show the Notes workspace, a linked material, and `Ctrl+K` global search.

## 6. Languages and personalization — 60 seconds

Switch English → Uzbek or Russian, show time/week preferences, then preview another accent/glass/density setting and Cancel it.

Explain that stored enum values stay canonical even when UI labels are translated.

## 7. Engineering — 45 seconds

Mention:

- Python + PySide6 + SQLite
- schema migrations through v4
- local `%APPDATA%\Mentor\` storage
- automated regression and Qt smoke tests
- Windows PyInstaller packaging

## 8. Close — 20 seconds

Describe Mentor as an evolving local-first teaching platform, with Teaching Mode and advanced calendar interactions planned next.
