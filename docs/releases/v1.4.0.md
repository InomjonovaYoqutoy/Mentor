# Mentor 1.4.0 — Global & Personal

## Focus
Localization, regional behavior, personalization, and a mature Settings experience.

## Added
- centralized localization infrastructure
- English, Uzbek (Latin), Russian
- canonical enum translation
- Qt locale-aware weekday/month presentation
- 12/24-hour time
- Monday/Sunday week start
- Day/Week default Schedule view
- localized duration and lesson-count grammar
- category-based Settings
- Orange/Amber/Graphite/Blue/Violet accents
- glass intensity
- Full/Reduced/Off motion
- Comfortable/Compact density
- atmospheric glow
- live appearance preview with Cancel rollback
- About page with app/schema/data-location details
- localization regression checks and Qt smoke cases

## Database
Schema remains v4. Preferences use the existing `settings` table.

## Downloads

- **MentorSetup.exe** — recommended Windows installer. Installs Mentor for the current user, creates Start Menu integration, optionally adds a desktop shortcut, and includes an uninstaller.
- **Mentor-portable-windows.zip** — portable packaged build for users who do not want to install the app.
- **SHA256SUMS.txt** — SHA-256 integrity hashes for both Windows packages.

The packaged application includes its Python/PySide6 runtime; end users do not need to install Python.

> The installer is currently unsigned, so Windows SmartScreen may display an Unknown publisher warning.
