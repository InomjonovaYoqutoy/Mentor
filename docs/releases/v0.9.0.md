# Mentor 0.9.0 — First Functional Build

## Purpose
Create a real persistent teaching-management desktop application rather than a visual prototype.

## Shipped
- local-first PySide6 + SQLite foundation
- Home dashboard with live database-backed data
- floating five-section navigation dock
- Day/Week Schedule
- session CRUD, status changes, overlap warning, recurrence
- Student manager
- Notes with search/tags/pin/archive
- Materials with file/URL references and missing-file handling
- Tasks and Goals
- database-backed Statistics
- Ctrl+K global search
- local reminders
- backup/restore, JSON export, student CSV export
- keyboard navigation
- first-run empty/sample workspace
- logging and exception handling
- PyInstaller workflow

## Storage
Application data is stored under `%APPDATA%\Mentor\`, separate from the executable/source directory.

## Validation note
The build was syntax-compiled and database/service smoke-tested. The original build environment could not launch PySide6, so visual runtime validation happened later on the target Windows system.
