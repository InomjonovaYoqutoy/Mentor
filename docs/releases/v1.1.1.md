# Mentor 1.1.1 — Quality Hotfix

## Goal
Stability and visual cohesion. No major feature expansion.

## Critical fixes
- Fixed lesson scheduling failure caused by an overlap SQL query joining `sessions` and `students` while referencing the shared `status` column without qualification.
- Added conflict-detection regression coverage.
- Added Notes persistence coverage.
- Removed the large Home Up Next / No upcoming lesson island.
- Rebuilt Notes as one unified workspace.
- Removed the decorative dock line.
- Replaced native quick-create menu styling with a custom frameless popover.
- Improved lesson subject-selection behavior.

## QA
