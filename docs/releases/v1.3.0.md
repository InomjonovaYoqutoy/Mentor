# Mentor 1.3.0 — Lessons & Assignments

## Focus
Connect lessons, attendance, notes, and homework into one teaching lifecycle.

## Added
- persistent assignments/homework
- student/lesson/material links
- due date, status, instructions, score/result
- homework surfaces on Home, Student Profile, Lesson Details, Search
- Lesson Detail workspace
- post-lesson wrap-up
- custom right-click lesson actions
- recurring-series IDs and scoped edits
- lesson templates
- Needs review state
- assignment completion statistics

## Database
Schema v4 added `assignments`, `lesson_templates`, and `sessions.series_id`.
