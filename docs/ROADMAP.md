# Roadmap

Planned directions after Mentor 1.4. These are **not shipped features** until they appear in a completed release.

## 1.5 — Teaching Mode (planned)

Potential scope:

- Start Lesson action
- elapsed lesson timer
- student context
- previous homework
- live lesson notes
- linked materials
- attendance
- complete/wrap-up action

## 1.6 — Advanced Calendar (planned)

Potential scope:

- drag lessons to reschedule
- resize lesson duration
- richer recurring-series editing
- stronger collision/availability feedback

## Longer-term directions

- controlled dashboard customization
- deeper teaching analytics
- additional languages
- stronger import/export workflows
- accessibility refinements
- more release/package automation

## Roadmap principle

**Functionality → Stability → UX → Visual quality → Animation → Extra features**
